## 'Job Finder Bot'

This bot automates the process of searching for job listings on job platforms.

## Features

- Automatically searches job boards for new postings.
- Filters results by location, category, and experience level.
- Extracts job details: title, location, date and link.
- Saves results to an Excel file for easy access.

## Technologies Used

- **Python**
- **Selenium WebDriver**
- **Pandas**
- **OpenPyXL** (for Excel export)
